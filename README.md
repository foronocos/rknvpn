# RKNVPN

Киберпанк-консоль: выбор узла, симуляция канала, тарифы с живой ценой и строки `vless://` / `hy2://` с QR.

Браузер не поднимает настоящий VPN-туннель. Идентификатор и настройки хранятся только локально. Строка нужна для импорта в отдельный клиент — узлы в ней учебные.

```bash
npm install
npm run dev
```
